# 臺灣常用呼吸系統藥物講義

本講義依「藥物類別」整理臺灣臨床最常見的呼吸系統藥物，涵蓋支氣管擴張劑、吸入型類固醇、白三烯與生物製劑，以及止咳化痰藥，每項列出學名、臺灣常見商品名與重點。中文商品名各廠牌不同，健保給付與供應可能異動，實際用藥以醫師處方與最新仿單為準。

> [!NOTE] 建議讀法
> 先讀第一節，分清楚「緩解（急救）」與「控制（長期）」兩種角色；之後每一類藥都問自己：它屬於哪一種角色、作用在哪一個受體或路徑。

## 一、氣道與治療目標速覽

氣喘的核心是**氣道慢性發炎**合併可逆的支氣管收縮；COPD 則以**不完全可逆的氣流受限**為主。因此氣喘以抗發炎（吸入型類固醇）為基礎，COPD 以長效支氣管擴張劑為基礎。

| 標的 | 藥物類別 | 角色 | 代表藥 |
| --- | --- | --- | --- |
| β₂ 受體（活化） | SABA／LABA | 擴張支氣管 | Salbutamol、Formoterol |
| M₃ 受體（阻斷） | SAMA／LAMA | 擴張支氣管、減少分泌 | Ipratropium、Tiotropium |
| 糖皮質素受體 | ICS／全身性類固醇 | 抗發炎（控制） | Budesonide、Prednisolone |
| 白三烯受體 | LTRA | 抗發炎、抗過敏 | Montelukast |
| IgE、IL-5 等 | 生物製劑 | 重度氣喘附加治療 | Omalizumab、Mepolizumab |
| 磷酸二酯酶 | 甲基黃嘌呤、PDE4 抑制劑 | 擴張支氣管／抗發炎 | Theophylline、Roflumilast |

| 縮寫 | 全名 | 意義 |
| --- | --- | --- |
| SABA | Short-acting β₂ agonist | 短效 β₂ 促效劑 |
| LABA | Long-acting β₂ agonist | 長效 β₂ 促效劑 |
| SAMA／LAMA | Short／Long-acting muscarinic antagonist | 短效／長效抗膽鹼藥 |
| ICS | Inhaled corticosteroid | 吸入型類固醇 |

## 二、β₂ 促效劑

活化支氣管平滑肌的 β₂ 受體，提高 cAMP 使平滑肌放鬆。共同副作用來自全身的 β₂ 作用：手抖、心悸、低血鉀、血糖上升。

### 1. 短效（SABA）

| 學名 | 臺灣商品名 | 用途與重點 |
| --- | --- | --- |
| Salbutamol | 泛得林 Ventolin | 急性發作緩解，數分鐘起效；頻繁使用代表控制不佳 |
| Terbutaline | 必理旺 | 口服與針劑；不可用於安胎 |
| Fenoterol ＋ Ipratropium | 備勞喘 Berodual | SABA 與 SAMA 複方，急性發作噴霧 |

### 2. 長效（LABA）

| 學名 | 臺灣商品名 | 用途與重點 |
| --- | --- | --- |
| Formoterol | 多為複方 | 起效快又長效，可做 ICS-formoterol 緩解用藥 |
| Salmeterol | 多為複方 | 起效慢，不可作急救 |
| Indacaterol | 多為複方 | 每日一次，COPD |
| Vilanterol | 多為複方 | 每日一次，與 Fluticasone furoate 或 Umeclidinium 組合 |

> [!WARNING] LABA 不可單用於氣喘
> 氣喘病人單用 LABA 會掩蓋發炎惡化、增加死亡風險，必須與 ICS 併用（通常是同一支複方吸入劑）。

## 三、抗膽鹼支氣管擴張劑

阻斷氣道 M₃ 受體，解除迷走神經造成的支氣管收縮並減少分泌。吸入劑幾乎不進腦，主要副作用是口乾；閉角性青光眼與攝護腺肥大仍需注意。

| 學名 | 臺灣商品名 | 用途與重點 |
| --- | --- | --- |
| Ipratropium | Atrovent | 短效（SAMA）；急性發作與 SABA 併用 |
| Tiotropium | Spiriva | 長效（LAMA），每日一次；COPD 基礎用藥，也用於重度氣喘附加 |
| Umeclidinium | 多為複方 | LAMA，每日一次 |
| Glycopyrronium | 多為複方 | LAMA，每日一次 |

## 四、類固醇

類固醇是氣喘控制的核心：降低氣道發炎、減少急性發作。吸入型將藥物送到局部、減少全身副作用；急性惡化時才使用短期全身性類固醇。

### 1. 吸入型（ICS）與複方

| 學名 | 臺灣商品名 | 用途與重點 |
| --- | --- | --- |
| Budesonide | Pulmicort | 單方 ICS；有霧化液，兒童常用 |
| Fluticasone propionate | Flixotide | 單方 ICS |
| Budesonide ＋ Formoterol | 吸必擴 Symbicort | ICS-LABA；可同時作維持與緩解（MART） |
| Fluticasone ＋ Salmeterol | 使肺泰 Seretide | ICS-LABA，維持用，不可作急救 |
| Fluticasone furoate ＋ Vilanterol | Relvar Ellipta | ICS-LABA，每日一次 |
| Fluticasone furoate ＋ Umeclidinium ＋ Vilanterol | Trelegy Ellipta | ICS-LAMA-LABA 三合一，COPD 與重度氣喘 |

ICS 局部副作用為口腔念珠菌感染與聲音沙啞；**吸完漱口**可大幅減少。COPD 病人長期使用 ICS 會增加肺炎風險，因此只在嗜酸性球偏高或反覆惡化時加上。

### 2. 全身性

| 學名 | 臺灣商品名 | 用途與重點 |
| --- | --- | --- |
| Prednisolone | — | 急性惡化口服短期療程 |
| Methylprednisolone | Solu-Medrol | 嚴重發作靜脈注射 |
| Hydrocortisone | Solu-Cortef | 靜脈注射；亦用於腎上腺危象 |

## 六、止咳與化痰藥

止咳只用於乾咳且影響生活時；有痰的咳嗽應以化痰為主，強行止咳可能讓痰液滯留。

### 1. 止咳藥

| 學名 | 臺灣商品名 | 類別 | 用途與重點 |
| --- | --- | --- | --- |
| Dextromethorphan | 美舒咳 Medicon | 中樞性（非鴉片受體） | 最常見的感冒止咳成分；與 MAOI、SSRI 併用有血清素症候群風險；高劑量有濫用問題 |
| Codeine | — | 中樞性（鴉片類） | 管制藥品；12 歲以下兒童禁用（CYP2D6 超快速代謝致呼吸抑制） |
| Benproperine | — | 周邊＋中樞 | 乾咳 |

## 七、氣喘與 COPD 治療階梯

### 1. 氣喘（GINA 概念）

| 嚴重度 | 首選路徑（Track 1） |
| --- | --- |
| 輕度、症狀偶發 | 需要時使用低劑量 ICS-formoterol |
| 每天有症狀或夜間發作 | 低劑量 ICS-formoterol 維持＋緩解（MART） |
| 控制不佳 | 中劑量 ICS-formoterol MART |
| 仍控制不佳 | 加 LAMA、評估表型，轉介考慮生物製劑 |

GINA 已不建議成人與青少年「只用 SABA、不用 ICS」，因為單用 SABA 會增加嚴重發作與死亡風險。

### 2. COPD（GOLD 概念）

| 情況 | 起始治療 |
| --- | --- |
| 症狀輕、少惡化 | 一種長效支氣管擴張劑（LAMA 或 LABA） |
| 症狀明顯 | LAMA ＋ LABA |
| 反覆惡化且嗜酸性球 ≥ 300／μL | LAMA ＋ LABA ＋ ICS |
| 仍反覆惡化 | 考慮 Roflumilast 或 Azithromycin |

## 八、字尾辨識法

| 字尾 | 類別 | 例子 |
| --- | --- | --- |
| -terol | 長效 β₂ 促效劑 | Formoterol、Salmeterol、Indacaterol、Vilanterol |
| -tropium | 吸入型抗膽鹼藥 | Ipratropium、Tiotropium |
| -onide／-asone | 類固醇 | Budesonide、Fluticasone |
| -lukast | 白三烯受體拮抗劑 | Montelukast |
| -mab | 單株抗體 | Omalizumab、Mepolizumab |
| -phylline | 甲基黃嘌呤 | Theophylline、Aminophylline |

例外：Salbutamol 與 Terbutaline 是短效 β₂ 促效劑，但不是 -terol 字尾。

## 九、重點總結與臨床情境

呼吸系統藥物在臨床最常出現於下列情境。

| 情境 | 常用藥物 |
| --- | --- |
| 氣喘急性發作（到院前） | Salbutamol 或 Salbutamol ＋ Ipratropium 噴霧、給氧 |
| 重度氣喘、初始治療反應差 | 全身性類固醇、Magnesium sulfate IV |
| 氣喘長期控制 | ICS 或 ICS-formoterol（MART） |
| COPD 長期治療 | LAMA ＋ LABA，必要時加 ICS |
| COPD 急性惡化 | SABA ± SAMA、短期口服類固醇、有感染徵象時抗生素 |
| 過敏性鼻炎合併氣喘 | Montelukast |
| 有痰咳嗽 | Acetylcysteine、Ambroxol |

> [!WARNING] 必背警示
> 1. 氣喘不可單用 LABA；一定與 ICS 併用。
> 2. 非選擇性 β 阻斷劑（Propranolol、Timolol 眼藥水）可誘發支氣管痙攣，氣喘禁用。
> 3. Theophylline 治療窗窄，注意併用藥物與吸菸對濃度的影響。
> 4. ICS 吸完要漱口，預防口腔念珠菌。
> 5. Codeine 12 歲以下禁用；Montelukast 注意神經精神副作用。
